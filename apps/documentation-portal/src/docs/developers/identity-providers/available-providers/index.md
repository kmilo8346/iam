Tenemos ya integrados los proveedores de autenticación listados a continuación:

- [Github][1]: Proovedor de un sistema de control de versiones especialmente usado para mantenimiento de código fuente.

- [Google][2]: Proovedor social de Google via autenticación por cuenta de google (email), se usa generalmente para accesos de cualquier alcance.

- [Microsoft Adfs][3]: Proveedor corporativo de Cencosud, que nos permite identificar una identidad digital corporativa de cencosud via microsoft.
