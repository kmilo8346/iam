# Usuarios y servicios

Los **usuarios** y **servicios** son las entidades que acceden a recursos. Un ejemplo de servicios son los servidores de terceros que necesitamos otorgar acceso a nuestro sistema. A los servicios se le assignan credenciales de acceso de mayor duración ([Api Keys](../../../api/applications/apikeys/)), a los usuarios en cambio se les assignan credenciales de corta duracción (**Token de Acceso**). Es importante entender que las [Api Keys](../../../api/applications/apikeys/) nunca deberán ser almacenadas del lado del cliente por motivos de seguridad.
